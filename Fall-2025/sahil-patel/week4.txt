## NOTES
- Use only ISA-approved forms: VM/VV/VS/VI/SA (no extra forms).
- Default integer type is 64-bit; avoid silent 32-bit behavior.
- Enforce vector element type + width rules; reject mixed widths in one instruction.
- PPCI remains the fast path to reach “compile to assembly”; LLVM is a future option.
