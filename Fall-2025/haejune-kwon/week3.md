### Some concepts I leared:
- Convolution: a way to merge a bigger portion of data into a smaller portion by adding the neighboring values to the center. Purpose of it is to reduce size of data for future calculations, reducing hardware constraints.
- Systolic array: A hardware architecture to represent a grid of processing elements. It is useful for repeating the simple operation constantly.
- GEMM (General Matrix Multiply): A matrix multiplication, often done by systolic array.
